# Password Strength Checker

A simple Java-based console application that checks password strength using basic validation rules.

This project was developed to practice Core Java concepts, methods, conditional statements, loops, and string handling.

## Technologies Used

- Java
- Core Java
- IntelliJ IDEA
- Git & GitHub

## Features

- Checks whether a password contains an uppercase letter.
- Checks whether a password contains a lowercase letter.
- Checks whether a password contains a digit.
- Uses separate methods for password validation.
- Provides a simple console-based user interaction.

## Validation Methods

| Method | Purpose |
|---|---|
| `hasUppercase()` | Checks for uppercase letters |
| `hasLowercase()` | Checks for lowercase letters |
| `hasDigit()` | Checks for numeric digits |

## Example

**Sample password:**

```text
Hello123
```

The application checks:
- Uppercase letter: Present
- Lowercase letter: Present
- Digit: Present

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/developerjasveersingh03/Password-Strength-Checker.git
```

2. Open the project in IntelliJ IDEA.

3. Open `src/Main.java`.

4. Run the `Main` class.

5. Enter a password when prompted and view the validation result.
